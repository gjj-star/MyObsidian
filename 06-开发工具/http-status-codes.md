## HTTP 状态码

## 五类全景

| 类别 | 含义 | 常见码 |
|---|---|---|
| 1xx | 信息响应 | 100-103 |
| 2xx | 成功 | 200 / 201 / 204 / 206 |
| 3xx | 重定向 | 301 / 302 / 304 / 307 / 308 |
| 4xx | 客户端错误 | 400-451 |
| 5xx | 服务端错误 | 500-504 |

## 日常最常用 14 个

- **200** 成功；**201** 已创建；**204** 无内容；**206** 部分内容
- **301** 永久重定向 vs **302** 临时重定向（缓存差异是经典坑）；**304** 未修改（缓存命中）；**307/308** 保留方法的重定向
- **400** 请求错误；**401** 未认证 vs **403** 无权限（易混）；**404** 不存在；**405** 方法不允许；**422** 参数校验失败；**429** 限流
- **500** 服务器内部错误；**502** 网关错误；**503** 服务不可用；**504** 网关超时

## 非标准码（代理/云厂商）

- Cloudflare 52x：520-530（**524** = 源站响应超时）
- Nginx **499**（客户端断开）；AWS ELB 460/463；IIS 440/449
