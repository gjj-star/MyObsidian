## 主链路

主链路是系统中**最核心的端到端业务流程**。例如电商的主链路：浏览 → 加购 → 下单 → 支付 → 履约。

## 特征

- **高频**：绝大多数用户流量都走这条链路
- **高价值**：直接承载核心业务价值（交易、转化）
- **高可用要求**：主链路故障 = 业务瘫痪，需要最高优先级的监控与保障
