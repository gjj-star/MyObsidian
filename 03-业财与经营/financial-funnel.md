## 财务漏斗

财务语境下的"漏斗"借鉴销售漏斗概念，指资金或财务指标从起点到终点**层层衰减**的过程。核心逻辑是追查每一层"漏"在哪里、漏了多少。

## 四大常见场景

| 漏斗 | 链路 |
|---|---|
| 收入漏斗 | 报价 → 签约 → 确认收入 → 现金回款 |
| 利润漏斗 | 毛收入 → 净利润逐层扣减（成本/费用/税） |
| 预算执行漏斗 | 预算批复 → 实际支出 → 有效支出 |
| 现金流漏斗 | 账面利润 → 经营现金流 |
