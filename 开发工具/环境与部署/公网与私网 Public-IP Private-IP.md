# 公网与私网 Public-IP Private-IP

**英文**：Public Network（公网）；Private Network（私网）；LAN（Local Area Network，局域网）；WAN（Wide Area Network，广域网）；NAT（Network Address Translation，网络地址转换）；IANA（Internet Assigned Numbers Authority，互联网数字分配机构）

公网、私网、内网、外网没有绝对定义，是**参考系选择的结果**：对你而言的外网，可能是别人的内网。

## 一般约定（相对防火墙）

| 概念 | 含义 |
|---|---|
| 内网 / 局域网 LAN | 防火墙内部、小范围组网（学校、公司、机关），封闭型 |
| 外网 / 广域网 WAN | 防火墙外部，连接不同地区局域网的远程网络 |
| 公网 | 人人都能访问的网络（IP 世界唯一） |
| 私网 | 未经授权无法访问的网络（局域网是某种意义上的私网） |

广义上：外网 ≈ 公网，内网 ≈ 私网。但大型网络内部的自建骨干网络也叫"公网"（如政务外网的公共部分不能上互联网却叫公网），需具体问题具体分析。

## NAT 地址转换

NAT 把内部私有 IP 翻译成合法公网 IP：多台内网机器共用一个公网 IP 上网，解决 IPv4 地址紧缺。家庭/校园场景常有多级 NAT（校园网关本身也可能只是个大局域网）。

## 内网 IP 与公网 IP 的本质区别

- 公网 IP 世界范围唯一；内网 IP 只在局域网内部唯一
- 一个局域网内机器内网 IP 互不相同，但共用一个外网 IP
- 保留 IP 段（IANA 划定，见即局域网）：A 类 `10.0.0.0/8`、B 类 `172.16.0.0/12`、C 类 `192.168.0.0/16`
- 类比：酒店 201 房是内网 IP（酒店内唯一），"某某市某某区某某酒店"是公网 IP（世界唯一）
- 经验法：电信 ADSL 升级大带宽后 99.99% 是内网 IP；代理网络运营商（长城宽带等）99.99% 内网 IP
