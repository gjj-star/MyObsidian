# 样式自定义方案菜单

> 每个元素给 5-6 个候选方案（按你的偏好：低饱和、克制、卡片感、Tokyo Night 暗底系）。
> **挑选方式**：回编号组合给我，如「1b 2a 3b 11d」；「a」= 保持现状，不选也行。
> **[保护]** 标记的是你手搓的专用设计，不纳入通用样式、不做改动。

- 5b 外链蓝色区分 · 6b Mermaid 容器化暗色适配（含可见性优化）· 7e 任务绿色勾

- 15b 亮色模式米白适配 · 16f 阅读全宽

## 1. 数学公式（块级 34 个 / 行内 2 个，算法笔记）

- 1a 保持现状（主题默认渲染）
- 1b 静默居中：块公式水平居中 + 上下留白加大，字色跟正文灰蓝
- 1c 左侧色条：块公式左边 3px 蓝条（与引用块同构但用蓝色系区分）
- 1d 卡片式：细边框 + 圆角 + 浅底，与 callout 家族统一
- 1e 悬停提亮：默认柔和低对比，鼠标悬停时提亮
- 1f 行内公式细分：行内 `$…$` 加浅蓝底轻微区分

## 2. Callout 类型补全（重点：abstract）

- 2a 仅补 abstract，青紫色（#bb9af7 系）——"一句话骨架/结论"专用
- 2b 补 abstract + 全类型一次到位（success/danger/note/todo/failure 等统一配色）
- 2c abstract 用金色系（与正文蓝色错开，呼应"骨架"的珍贵感）
- 2d abstract 压扁化：比其它 callout 更矮更紧凑（结论条形态）
- 2e abstract 横幅化：居中、带宽边、像引言

## 3. 高亮 ==（13 处）

- 3a 保持现状（默认黄底）
- 3b 暗底适配：蓝紫半透明底（#7aa2f7 约 22% 透明），文字不变
- 3c 暖黄低饱和（#e0af68 约 20%）
- 3d 下划线式：无底色，虚线下划线
- 3e 荧光笔式：渐变底色（左深右浅）
- 3f 标记式：底色 + 左缘 2px 色条

## 4. 图片 / 嵌入（5 处）
