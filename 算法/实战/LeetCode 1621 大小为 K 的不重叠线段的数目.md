# 1621. 大小为 K 的不重叠线段的数目笔记

> [!info] 题目原文（LeetCode 1621 大小为 K 的不重叠线段的数目）
> 给你一维空间的 `n` 个点，其中第 `i` 个点（编号从 `0` 到 `n-1`）位于 `x = i` 处。
>
> 请你找出**恰好** `k` 条不重叠线段的方案数。线段可以共用端点，但是不能重叠；`k` 条线段不需要覆盖全部 `n` 个点；线段两个端点都必须是整数坐标。
>
> 由于答案可能很大，请返回对 `10^9 + 7` 取余后的结果。
>
> **示例 1：**
>
> - 输入：`n = 4, k = 2`
> - 输出：`5`
> - 解释：例如 `{(0,2),(2,3)}`、`{(0,1),(1,3)}` 等共 5 种方案。
>
> **示例 2：**
>
> - 输入：`n = 3, k = 1`
> - 输出：`3`
> - 解释：`{(0,1)}`、`{(0,2)}`、`{(1,2)}`。
>
> **示例 3：**
>
> - 输入：`n = 30, k = 7`
> - 输出：`796297179`
> - 解释：原总数 3796297200，取余后所得。
>
> **示例 4：**
>
> - 输入：`n = 5, k = 3`
> - 输出：`7`
>
> **示例 5：**
>
> - 输入：`n = 3, k = 2`
> - 输出：`1`
>
> **提示：**
>
> - `2 <= n <= 1000`
> - `1 <= k <= n-1`

## 一、最开始的暴力思路

先考虑 `k = 2`。

把线段分为左右两条：

```text
左线段：(i, j)
右线段：(a, b)
```

因为左线段在左，右线段在右，所以合法条件为：

```text
i < j <= a < b
```

定义两条线段之间的距离：

```text
d = a - j
```

因为题目允许线段共用端点，所以：

```text
d >= 0
```

其中：

```text
d = 0
```

也是合法的。

最开始我的想法：

> 枚举所有符合条件的情况，就是左线段右端点和右线段左端点的距离 `d >= 0`。
> 在给定 n 个整数点里，遍历所有 `d=0` 的情况，遍历完后 `d+=1`，同时线段的长度不能 `<1`，还要考虑线段的不同长度。

于是除了距离，还要枚举线段长度：

```text
len1 = j - i >= 1
len2 = b - a >= 1
```

因此一个方案其实由：

```text
起始位置 i
左线段长度 len1
间距 d
右线段长度 len2
```

共同决定。

## 二、推广到 k = 3

三条线段：

```text
(i, j)
(a, b)
(c, e)
```

满足：

```text
i < j <= a < b <= c < e
```

我最开始写：

```text
len1 = i - j >= 1
len2 = a - b >= 1
len3 = c - e >= 1
```

这里方向写反了，正确应该是：

```text
len1 = j - i >= 1
len2 = b - a >= 1
len3 = e - c >= 1
```

间距：

```text
d1 = a - j >= 0
d2 = c - b >= 0
```

于是暴力枚举为：

```text
ans = 0

枚举 d1，从 0 开始
    枚举 d2，从 0 开始
        枚举 len1，len1 >= 1
            枚举 len2，len2 >= 1
                枚举 len3，len3 >= 1
                    枚举左线段起点 i

                        j = i + len1
                        a = j + d1
                        b = a + len2
                        c = b + d2
                        e = c + len3

                        如果 e < n：
                            ans += 1
```

由此发现规律：

```text
k = 2：
2 个 len
1 个 d

k = 3：
3 个 len
2 个 d

k 条线段：
k 个 len
k - 1 个 d
```

---

## 三、从多层循环想到 DFS

如果 `k` 不固定，就不可能手写：

```text
d1
d2
d3
...

len1
len2
len3
...
```

这么多层循环。

于是可以把“不断选择下一条线段”抽象成 DFS。

当前状态：

```text
dfs(已经选了几条线段, 上一条线段的右端点)
```

下一条线段枚举：

```text
新线段的起点 + 长度
```

或者更直接：

```text
新线段的起点 left
新线段的终点 right
```

需要满足：

```text
left >= last_end
right > left
```

因为：

```text
left == last_end
```

表示共用端点，合法。

---

## 四、开始发现重复状态

如果第一条线段不同，后面剩下的选择空间不同。

例如前面结束得越早：

> 后面剩余的点越多，可以选择的线段越多。

于是开始想到：

> 其实没必要一直记住前面具体选了什么，只需要知道现在还有多少点，以及还要选多少条线段。

因此定义动态规划状态：

```text
dp[n][k]
```

表示：

> 前 `n` 个点中，选择 `k` 条不重叠线段的方案数。

这里 `n` 和 `k` 的真实范围其实是：

```text
n ∈ [0, N]
k ∈ [0, K]
```

所以代码里数组需要：

```python
dp = [[0] * (K + 1) for _ in range(N + 1)]
```

这里的 `+1` 不是固定模板，而是因为我们隐性定义了：

```text
0 ~ N
0 ~ K
```

都属于合法的 DP 状态。

---

# 五、先看 k = 1

`n` 个点选择一条线段。

长度为 `1`：

```text
n - 1 种
```

长度为 `2`：

```text
n - 2 种
```

……

长度为 `n-1`：

```text
1 种
```

所以：

$$
dp[n][1]
=
(n-1)+(n-2)+\cdots+1
$$

即：

$$
dp[n][1]=\frac{n(n-1)}2
$$

这里我第一反应是：

> 长度等差增长，种类也等差减小，可以用三角形数求和公式。

这个在 `k=1` 时成立。

但一般的 `k` 下：

```text
dp[1][k]
dp[2][k]
dp[3][k]
...
```

并不是等差数列，所以不能继续使用三角形数公式。

不过“**不要每次重新求和，要维护这个和**”的方向是对的。

于是引出了前缀和。

---

# 六、前缀和 pre

定义：

```text
pre[n][k]
```

表示：

$$
pre[n][k]
=
dp[1][k]+dp[2][k]+\cdots+dp[n][k]
$$

也就是：

> 保存这一列 DP 到当前 `n` 为止的累计方案数。

所以：

```python
pre = [[0] * (K + 1) for _ in range(N + 1)]
```

这里的 `pre` 是辅助状态数组。

它存在的目的：

> 避免每次重新计算一整段 `dp` 的和。

---

# 七、状态转移

计算：

```text
dp[n][k]
```

分成两类。

### 情况 1：最后一个点不作为新线段的右端点

相当于只使用前 `n-1` 个点：

$$
dp[n-1][k]
$$

### 情况 2：最后一条线段以最后一个点为右端点

最后一条线段的左端点可以出现在前面的不同位置。

于是会产生：

$$
dp[1][k-1]
+
dp[2][k-1]
+
\cdots
+
dp[n-1][k-1]
$$

刚好就是：

$$
pre[n-1][k-1]
$$

所以：

$$
\boxed{
dp[n][k]
=
dp[n-1][k]+pre[n-1][k-1]
}
$$

而前缀和本身：

$$
\boxed{
pre[n][k]
=
pre[n-1][k]+dp[n][k]
}
$$

---

# 八、初始化

一开始我觉得：

```text
dp[n][0] = 0？
```

但这里要区分：

```text
选 0 条线段
```

和：

```text
有 0 种方案
```

不是一回事。

`n` 个点选择 `0` 条线段：

> “什么都不选”本身就是一种方案。

所以：

$$
\boxed{dp[n][0]=1}
$$

而：

```text
0 个点选 k 条线段
```

则：

$$
dp[0][0]=1
$$

$$
dp[0][k]=0\qquad(k>0)
$$

因为 `pre` 定义为：

$$
pre[n][k]
=
dp[1][k]+\cdots+dp[n][k]
$$

所以：

$$
pre[0][k]=0
$$

并且：

$$
pre[n][0]
=
1+1+\cdots+1
=
n
$$

---

# 九、二维 DP 实现

```python
class Solution:
    def numberOfSets(self, N: int, K: int) -> int:
        MOD = 10**9 + 7

        # dp[n][k]：前 n 个点中选 k 条不重叠线段的方案数
        dp = [[0] * (K + 1) for _ in range(N + 1)]

        # pre[n][k]：前缀和，保存 dp[1][k] 到 dp[n][k] 的累计方案数
        pre = [[0] * (K + 1) for _ in range(N + 1)]

        # n 个点选 0 条线段：只有一种方案（什么都不选）
        for n in range(N + 1):
            dp[n][0] = 1

        # pre[n][0] = dp[1][0] + ... + dp[n][0] = n
        for n in range(1, N + 1):
            pre[n][0] = pre[n - 1][0] + dp[n][0]

        # 状态转移
        for n in range(1, N + 1):
            for k in range(1, K + 1):
                dp[n][k] = (
                    dp[n - 1][k] + pre[n - 1][k - 1]
                ) % MOD

                pre[n][k] = (
                    pre[n - 1][k] + dp[n][k]
                ) % MOD

        return dp[N][K]
```

时间复杂度：

$$
O(NK)
$$

空间复杂度：

$$
O(NK)
$$

# 十、降维：滚动数组

二维状态：

```text
dp[n][k]
pre[n][k]
```

在计算第 `n` 行的时候，只需要上一行：

```text
dp[n-1][k]
pre[n-1][k]
```

更早的：

```text
n-2
n-3
...
```

都不会再单独访问。

因此可以只保存一行。

二维：

```python
dp[n][k] = dp[n - 1][k] + pre[n - 1][k - 1]
```

降维后：

```python
dp[k] = dp[k] + pre[k - 1]
```

其中更新前的：

```text
dp[k]
```

就是上一轮的：

```text
dp[n-1][k]
```

而：

```text
pre[k-1]
```

必须仍然是上一轮：

```text
pre[n-1][k-1]
```

所以需要倒序更新 `k`。

```python
class Solution:
    def numberOfSets(self, N: int, K: int) -> int:
        MOD = 10**9 + 7

        dp = [0] * (K + 1)
        pre = [0] * (K + 1)

        dp[0] = 1

        for n in range(1, N + 1):
            for k in range(K, 0, -1):
                dp[k] = (dp[k] + pre[k - 1]) % MOD
                pre[k] = (pre[k] + dp[k]) % MOD

            pre[0] = (pre[0] + dp[0]) % MOD

        return dp[K]
```

时间复杂度仍然：

$$
O(NK)
$$

空间复杂度变为：

$$
O(K)
$$

> 关于滚动数组“为什么要倒序、倒序为什么可行”的完整推理，已单独整理为 [[滚动数组 为什么倒序，倒序为什么可行]]。

# 十一、组合数学

合法的 `k` 条线段端点满足：

$$
0\le l_1<r_1\le l_2<r_2\le\cdots\le l_k<r_k<n
$$

麻烦在：

$$
r_i\le l_{i+1}
$$

这里允许等号，也就是允许两条线段共用端点。

为了把 `≤` 变成严格的 `<`，令：

$$
l_i'=l_i+(i-1)
$$

$$
r_i'=r_i+(i-1)
$$

也就是：

```text
第 1 条线段：不动
第 2 条线段：右移 1
第 3 条线段：右移 2
...
第 k 条线段：右移 k-1
```

于是原来的：

$$
r_i\le l_{i+1}
$$

会变成：

$$
r_i'<l_{i+1}'
$$

最终得到：

$$
0\le l_1'<r_1'<l_2'<r_2'<\cdots<l_k'<r_k'<n+k-1
$$

也就是：

> 从 `n+k-1` 个不同位置中选择 `2k` 个端点。

因此答案：

$$
\boxed{
\binom{n+k-1}{2k}
}
$$

这里的核心不是“平移以后碰巧一样”，而是：

> 平移前后的方案可以一一对应，变换可逆，所以方案数量不变。

# 十二、这题我的完整思路变化

最开始：

> 枚举距离 `d`，同时还要考虑线段的不同长度。

然后推广：

```text
k 条线段
→ k 个 len
→ k-1 个 d
```

再发现：

> `k` 不固定，不能一直手写多层循环。

于是想到 DFS：

```text
不断选择下一条线段
```

然后又发现：

> 很多不同的选择最终进入的是同一个“剩余点数 + 剩余线段数”状态。

于是进入 DP：

```text
dp[n][k]
```

接着状态转移里出现：

```text
一大串 dp 求和
```

我的第一反应：

> 能不能用三角形数求和公式维护？

发现只有 `k=1` 是等差数列，但“维护求和”的方向正确，于是换成：

```text
pre 前缀和
```

最终得到：

$$
dp[n][k]=dp[n-1][k]+pre[n-1][k-1]
$$

然后又发现只依赖上一行，所以进一步使用：

```text
滚动数组
```

将空间：

$$
O(NK)
$$

降到：

$$
O(K)
$$

最后官方组合数学又从另外一个方向发现：

> 其实最终就是对 `2k` 个端点做一个可逆平移，然后直接组合。

# 十三、这题最值得记住的地方

这题和 [[LeetCode 2472 不重叠回文子字符串的最大数目]] 一样，也可以分成三个层次。

**第一层：题目本质**

不是：

```text
随便画 k 条线段
```

而是：

```text
在 n 个点的整数坐标约束下
统计恰好 k 条互不重叠线段的方案数
```

线段可共用端点（`≤` 而非 `<`），这正是后面所有麻烦的来源。

**第二层：DP 骨架**

```text
发现重复状态：
剩余点数 + 还需选的线段数 决定一切
```

于是：

```text
dp[n][k]：前 n 个点选 k 条线段的方案数
```

转移时出现“一大串 dp 求和”，用前缀和维护：

$$
dp[n][k]=dp[n-1][k]+pre[n-1][k-1]
$$

再发现只用上一行，滚动数组降维：

$$
O(NK)\ \text{空间} \rightarrow O(K)
$$

**第三层：组合数学的降维打击**

允许共用端点（`≤`）让直接组合很别扭，但平移：

$$
l_i'=l_i+(i-1),\qquad r_i'=r_i+(i-1)
$$

可以把 `≤` 变成 `<`，且变换可逆、方案一一对应，于是答案直接是：

$$
\binom{n+k-1}{2k}
$$

## 我自己的阶段总结

> 这题我一开始只想着“枚举距离 d、枚举每段长度”，层数随 k 越长越多，根本写不完；后来把“不断选择下一条线段”抽象成 DFS，又发现真正决定未来的只有“剩余点数 + 剩余线段数”，于是进入 DP；转移里的连续求和靠前缀和 pre 维护；再发现只依赖上一行，就用滚动数组把空间从 O(NK) 压到 O(K)——顺带把“为什么倒序、倒序为什么可行”彻底搞清了（单独成篇）。
>
> 而官方解法从组合数学给出了另一个完全不同的入口：允许共用端点让 `≤` 很别扭，但把第 i 条线段整体右移 i-1 位，`≤` 就变成了 `<`，全部端点从 n+k-1 个位置里选 2k 个即可，一步得出 C(n+k-1, 2k)。
>
> **暴力负责“看清结构”，DP 负责“稳定求解”，组合数学负责“降维打击”。三种视角互相印证，才是这题最值钱的部分。**
