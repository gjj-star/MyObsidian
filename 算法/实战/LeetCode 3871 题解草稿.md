【正文】

这题我第一版是"按第几个逗号"数的，这次换个角度：**按区间统计**。

【正文】

观察一下标准格式：

【无序列表】

```markdown
- 1~999：没有逗号（0 个）
- 1000~999999：每个数 1 个逗号
- 1000000~999999999：每个数 2 个逗号
- 以此类推
```

【正文】

所以每个区间里的数字，**逗号数量是一模一样的**。那这一段的逗号总数就是：

【引用 + 加粗】

```markdown
> 区间长度 × 该区间每个数的逗号数
```

【正文】

不用管数字之间怎么互相叠加，每段独立算完加进总数就行。

【二级标题 H2】

```markdown
## 解题过程
```

【三级标题 H3】

```markdown
### 第一步：确定每个区间的左右边界
```

【正文】

左边界就是从 1000 开始，每次乘 1000：

【纯文本代码块】

````markdown
```text
left = 1000 → 1000000 → 1000000000 → ...
```
````

【正文】

右边界是这个区间的最大值（比如 1000 这一段的右边界是 999999），但如果 n 还没到区间末尾，就取 n：

【代码块】

````markdown
```python
right = min(n, left * 1000 - 1)
```
````

【三级标题 H3】

```markdown
### 第二步：区间长度 × 逗号数
```

【正文】

区间长度是 `right - left + 1`，每段对应的逗号数就是循环次数 `count`（从 1 开始，每升一段 +1）：

【代码块】

````markdown
```python
comma += (right - left + 1) * count
```
````

【三级标题 H3】

```markdown
### 第三步：循环到 n 装不下为止
```

【正文】

`left` 一路乘 1000 往上走，一旦超过 n 就停（说明后面的区间根本不存在）。

【二级标题 H2】

```markdown
## 复杂度
```

【无序列表】

```markdown
- 时间复杂度：O(log n)。每三位升一段，循环次数 ≈ 位数 / 3，n 再大也就几十次
- 空间复杂度：O(1)，就三个变量
```

【二级标题 H2】

```markdown
## Code
```

【代码块（Python3）】

````markdown
```python
class Solution:
    def countCommas(self, n: int) -> int:
        comma = 0
        left = 1000
        count = 1
        while n >= left:
            right = min(n, left * 1000 - 1)
            comma = comma + (right - left + 1) * count
            left *= 1000
            count += 1
        return comma
```
````

【正文 + 加粗】

```markdown
**一句话总结**：每个区间里的数逗号数都一样，所以整段 = 区间长度 × 逗号数，逐段加完即可。
```
