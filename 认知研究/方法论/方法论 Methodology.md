方法论是对"怎么知道"这件事的研究和规范——不是具体操作方法，而是**关于方法的方法**。

**英文**：Methodology（MTD）

## 方法 ≠ 方法论

| | 方法（Method） | 方法论（Methodology） |
|---|---|---|
| 问什么 | "怎么做？" | "为什么这样做？" |
| 层面 | 具体步骤 | 选择方法的原则和逻辑 |

方法论意识：不仅问"怎么做"，还要问"边界在哪——什么条件下有效、什么条件下失效"。

## 三个核心问题

1. **知识论问题**（Epistemology）：我们怎么知道一件事是真的？（理性 Reason / 经验 Experience / 证伪 Falsification / 权威 Authority / 直觉 Intuition）
2. **边界问题**（Boundary）：这方法能处理什么，不能处理什么？（知道无力区是方法论素养核心）
3. **反身问题**（Reflexivity）：观察者在知识生产中的位置是什么？

## 不同领域的"对"的标准

| 领域 | 方法论核心 | "对"的标准 |
|---|---|---|
| 自然科学 | 实验、证伪、可重复（Reproducibility） | 预测与观测一致 |
| 数学/逻辑 | 公理演绎、证明 | 内部无矛盾 |
| 社会科学 | 统计推断（Statistical Inference）、田野调查 | 解释力、可推广性 |
| 历史学 | 史料考证、交叉印证 | 证据链完整且无矛盾 |
| 法学 | 法条解释、判例类推 | 合规范性+合目的性 |
| 工程技术 | 设计-构建-测试迭代 | 能跑、能用、不崩 |
| 六爻/八字 | 体系内五行生克推演 | 内部逻辑自洽+事后解释覆盖 |

关键洞察：不同领域的方法论追求的根本不是同一种"对"。无方法论意识者会拿 A 领域标准评判 B 领域。

## 与六爻实测的关联

- "体系内推演 vs 外部验证" → 划方法的边界
- 主动预测+事前锁死标准 → 给"准不准"设定操作化标准（方法论设计）
- 意识到反身性 → 考虑观察者在系统内的位置
