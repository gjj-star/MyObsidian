# SOP 定义

SOP（Standard Operating Procedure，标准作业程序）——把一项工作拆成固定的、可重复执行的步骤，任何人照着做都能得到相同结果。

**英文**：Standard Operating Procedure（SOP）

## 四大关键特征

- **步骤化**：每一步编号，不跳不绕
- **可重复**：同一人做一百次，结果一致
- **可复制**：换人做，结果一样
- **可检验**：每步做没做、对不对，都能检查

## 与说明书/教程的区别

SOP 与说明书、教程在目的、粒度和分支处理上定位完全不同：

| | 说明书 | 教程 | SOP |
|---|---|---|---|
| 目的 | 让人知道功能 | 让人学会技能 | 让人完成具体操作 |
| 粒度 | 粗 | 中 | 细——精确到"点哪个按钮""填什么字段" |
| 分支判断 | 无 | 偶尔 | 有——"A情况走步骤3a，B情况走3b" |

## 为什么需要

1. **消除人的差异性**——老员工走了，新人不出错
2. **锁定质量标准**——不是"尽力"，而是"必须"
3. **规模化前提**——一百个店没有 SOP 就崩
4. **责任追溯**——逐步骤复盘，知道哪一步掉了链子

## 典型场景

- 麦当劳炸薯条（油温/时间/撒盐量全球统一）
- 医院术前核对（"病人叫什么""哪个部位动刀"）
- 软件上线流程（测试/审批/回滚条件）
- OA（Office Automation，办公自动化）审批流（审批操作 SOP 化）

## 局限性

- 只能处理已知问题，规程外无效
- 过度 SOP 化 → 官僚主义，人不敢动脑子
- 维护成本——业务变了 SOP 没跟上，就是错的

## 应用

先判断业务链是否值得 SOP 化，再进一步评估是否转成 Skill 交给 AI Agent 执行，是 Agent 工程方法论的第一环。
