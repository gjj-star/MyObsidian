# 八卦与五行基础

---

## 八卦口诀

每卦由三爻组成（自下而上），阳爻为「━━━━━」，阴爻为「━━ ━━」。

| 卦名 | 口诀 | 爻象 | 象征 |
|:----:|------|:----:|------|
| **乾** | 三连 | ━━━━━<br>━━━━━<br>━━━━━ | 天 |
| **坤** | 六断 | ━━ ━━<br>━━ ━━<br>━━ ━━ | 地 |
| **坎** | 中满 | ━━ ━━<br>━━━━━<br>━━ ━━ | 水 |
| **离** | 中虚 | ━━━━━<br>━━ ━━<br>━━━━━ | 火 |
| **艮** | 覆碗 | ━━━━━<br>━━ ━━<br>━━ ━━ | 山 |
| **震** | 仰盂 | ━━ ━━<br>━━ ━━<br>━━━━━ | 雷 |
| **兑** | 上缺 | ━━ ━━<br>━━━━━<br>━━━━━ | 泽 |
| **巽** | 下断 | ━━━━━<br>━━━━━<br>━━ ━━ | 风 |

> **速记**：乾三连、坤六断、坎中满、离中虚、艮覆碗、震仰盂、兑上缺、巽下断

## 五行生克

五行：**木 · 火 · 土 · 金 · 水**

### 相生（滋养关系）

```
木 → 火 → 土 → 金 → 水 → 木（循环）
```

| 生 | → | 被生 |
|:--:|:-:|:----:|
| 木 | → | 火 |
| 火 | → | 土 |
| 土 | → | 金 |
| 金 | → | 水 |
| 水 | → | 木 |

### 相克（制约关系）

```
木 → 土 → 水 → 火 → 金 → 木（循环）
```

| 克 | → | 被克 |
|:--:|:-:|:----:|
| 水 | → | 火 |
| 火 | → | 金 |
| 金 | → | 木 |
| 木 | → | 土 |
| 土 | → | 水 |

## 能量判断：旺·相·休·囚·死

以「我」为参照，判断某一行在特定时令中的能量状态：

| 状态 | 关系 | 含义 |
|:----:|------|------|
| **旺** | 与我同 | 当令最强 |
| **相** | 我生者 | 被滋养，次强 |
| **休** | 生我者 | 已完成使命，休息 |
| **囚** | 克我者 | 被当令之气压制 |
| **死** | 我克者 | 被我彻底压制，最弱 |

> **口诀**：我生相，生我休，克我囚，我克死

## 六亲体系

以「我」为中心，用五行生克关系推导六亲：

| 关系 | 五行逻辑 | 六亲 |
|------|----------|:----:|
| **生我者** | 母亲滋养子女 | 父母 |
| **我生者** | 子女由我而出 | 子孙 |
| **同我者** | 平等共处 | 兄弟 |
| **我克者** | 我所能支配 | 妻财 |
| **克我者** | 约束管制我 | 官鬼 |

> 记忆要点：生克方向决定了亲缘角色，是六爻断卦的核心框架。
