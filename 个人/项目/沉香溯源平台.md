# 沉香溯源平台

## 概述
面向沉香种植的全栈平台，覆盖知识教育、标准认证、市场交易和 AI 辅助植物护理。

## 子项目

### 1. 微信小程序（前端）
- 路径：`G:/WorkBuddy/GClaw/cxsyxcx/chenxiang-wechat-mini-program/`
- 技术栈：原生微信小程序框架
- AppID：`wx5230595bccbb9137`
- 后端 API：`https://www.cxbz.org.cn/api`

**功能模块：**
- 首页 / 个人中心
- 考试/学习（标准列表、练习、竞赛、成绩）
- 市场交易（发布、搜索、供求信息、支付）
- AI 助手（智能问答、病虫害图片鉴定）
- 用户管理（登录、收藏、订阅）

### 2. Java 后端
- 路径：`G:/WorkBuddy/GClaw/cxsyxcx/cx_planting/`
- 技术栈：Spring Boot 2.7.4 + MyBatis Plus + MySQL + Redis + JWT
- 模块：cx-common（基础设施）、cx-pojo（DTO/实体）、cx-server（业务逻辑）
- 集成：微信支付 APIv3、阿里云短信、Quartz 定时任务

### 3. Android App（移动端）
- 路径：`G:/WorkBuddy/GClaw/cxsysys-app/`
- 技术栈：Kotlin + Jetpack Compose + MVVM + Retrofit
- 后端 API：`https://dbcx.org.cn`
- 功能：母树管理、育苗、种植、灌溉、施肥、农药、病虫害、生长记录、修剪、打孔结香、采收
- 附加：蓝牙热敏打印模块
