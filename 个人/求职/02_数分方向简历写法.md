# 数分方向简历写法与可直接改写内容

## 1. 求职定位

### 推荐投递岗位名称
- 数据分析实习生
- 商业分析实习生
- 策略分析实习生
- 数据运营分析实习生
- 数据产品实习生（偏分析）

### 不建议在这一版简历里出现的意向
- AI产品经理
- 前端开发
- 爬虫工程师
- 游戏策划

原因很简单：这份简历的目标是让招聘方一眼把你归类成“能做分析的人”。

---

## 2. 数分简历的人设主张

你这份简历最合适的人设不是“算法竞赛选手”，也不是“纯 BI 制表员”，而是：

**具备大数据专业背景，能够使用 Python/SQL 完成数据清洗、特征工程、基础建模与可视化分析，并从业务问题出发形成用户分层、策略建议与分析结论。**

这个定位很适合你，因为它同时覆盖：
- 专业背景
- 数据处理能力
- 建模能力
- 商业理解

---

## 3. 数分简历推荐结构

## 基本信息
- 郭锦佳
- 电话 / 邮箱
- 学校 / 专业 / 年级
- 求职意向：数据分析实习生 / 商业分析实习生

## 个人简介
建议控制在 3 行以内，不要写成小作文。

### 可直接使用版本
**大数据管理与应用专业在读，具备 Python、SQL、Excel、Tableau 数据分析实践能力，能够完成行为日志清洗、特征工程、基础建模与结果可视化；曾围绕电商复购预测、文本挖掘等项目输出分析结论与业务建议，具备较强的业务理解与数据落地意识。**

---

## 4. 专业技能怎么写

数分版技能要遵循一个原则：

> 只保留对“分析岗”有帮助的内容，且按“数据处理 → 分析建模 → 可视化工具”顺序排列。

### 建议写法
## 专业技能
- **数据处理**：熟练使用 Python（Pandas、NumPy）进行数据清洗、特征构造、数据预处理与批量分析；熟悉 MySQL 多表查询、聚合分析与基础 SQL 语句编写。
- **分析建模**：具备机器学习基础，熟悉 LightGBM、XGBoost、逻辑回归等常用模型，能够结合业务目标完成基础建模、效果评估与结果解释。
- **数据可视化**：熟练使用 Excel、Tableau、ECharts 展示分析结果，能够输出图表看板与结论汇报。
- **分析思维**：能够围绕用户行为、转化、复购等业务问题设计分析框架，并输出用户分层与策略建议。

### 建议删掉或弱化的内容
- Vue 3
- 小程序开发
- Android Studio
- WebStorm
- 墨刀
- Apifox

这些内容放在数分简历里会稀释标签。

## 6. 项目经历可直接改写版本

## 项目一：基于用户行为分析的天猫新用户复购预测与精准营销策略研究
**核心成员｜2025.10 - 2025.12**

### 可直接写进简历的版本
- 围绕“新用户复购率低、营销资源有限”的业务问题，基于天猫 1GB+ 用户行为日志开展数据清洗、特征工程与复购预测分析。
- 针对原始数据体量大、直接读取易内存溢出的难点，设计“分块读取 + 向量化处理”方案，显著提升数据处理效率，将大规模日志清洗耗时由分钟级压缩至秒级。
- 构建用户活跃度、交互时间跨度、店铺回头客率等关键特征，并结合 LightGBM、XGBoost、CatBoost、Stacking 融合完成建模，最终 AUC 达到 **0.8959**。
- 基于预测结果进行高/中/低潜力用户分层，提出差异化营销建议，为优惠券投放、重点召回与低效触达控制提供数据依据。

### 面试时这段要能回答的问题
- 你做了哪些特征？
- 你为什么认为这些特征重要？
- 你如何把模型结果转成业务动作？
- 你在小组里具体负责什么？

如果这些问题你能讲明白，这段项目就会很强。

## 项目二：中文文本自动摘要工具
**独立开发｜2025.04 - 2025.06**

### 可直接写进简历的版本
- 针对长文本信息获取效率低的问题，独立完成中文文本自动摘要工具设计与实现，搭建从分词、停用词过滤到关键句抽取的完整文本处理流程。
- 基于 jieba、TextRank 等方法完成摘要生成逻辑，实现文本自动分句、关键词提取与摘要输出。
- 建立 ROUGE-1、ROUGE-2、ROUGE-L 指标评估体系，对摘要结果进行量化验证，提升算法结果的可解释性与可评估性。
- 通过该项目积累文本挖掘、指标验证与信息压缩场景下的数据分析能力。

### 这一段的价值
不是因为它一定最贴业务分析，而是它能证明：
- 你会处理非结构化数据
- 你有指标评估意识
- 你能独立完成小型分析/算法项目

## 项目三：数据分析/可视化/竞赛经历
如果你要放第三段，建议优先选“能体现分析结论”的项目，而不是纯技术实现项目。

### 可选写法 A：挑战杯/多源数据分析方向
- 围绕横琴多元主体社区融合问题，参与政府政策文本、统计年鉴与社交媒体文本的多源信息整理与分析。
- 通过语义分析、主题归纳与情感倾向提炼，识别社区治理中的核心议题与潜在摩擦点，为策略建议输出提供证据支持。

### 可选写法 B：可视化/课程汇报方向
- 围绕业务问题完成数据清洗、指标拆解与图表设计，使用 Tableau / ECharts 输出可视化图表与分析汇报材料。
- 能够将原始数据转化为结构化结论，支持面向业务方的汇报表达。

## 9. 数分简历最容易踩的坑

### 坑一：把自己写成“全栈万能型”
分析岗不想看你会不会 Vue，他们想看你会不会：
- SQL
- Python
- 数据清洗
- 指标理解
- 分析逻辑

### 坑二：只写模型名，不写业务问题
错误示范：
- 使用 LightGBM/XGBoost/CatBoost 训练模型

正确方向：
- 围绕复购预测问题，通过特征工程与模型融合识别高潜力用户，并输出分层营销建议

### 坑三：没有分析结果
一定要写出：
- 指标结果
- 分层结果
- 业务建议
- 你的具体贡献

## 10. 一页版内容优先级建议

如果简历只有一页，优先保留：
1. 个人简介
2. 数据技能
3. 天猫复购预测
4. 文本摘要/文本挖掘
5. 教育经历
6. 奖项

把不直接增强“分析岗可信度”的信息都砍掉。

---

## 11. 我对这份数分简历的建议总结

这份简历的核心，不是让别人觉得你“技术很杂很强”，而是让别人明确知道：

> 你能处理数据，能理解业务，能把分析结果转成建议。

只要这条主线稳住，这份简历就比你现在的海投混合版更有战斗力。
