# 感官过载 Sensory Overload

**英文**：Sensory Overload（感官过载）；Sensory Gating（感觉门控）；P50 抑制（P50 Suppression）；ADHD（Attention-Deficit/Hyperactivity Disorder，注意缺陷多动障碍）；ASD（Autism Spectrum Disorder，自闭症谱系障碍）

感官过载是指感官刺激（声音、光线、触觉、气味等）**超出大脑处理和过滤能力**时产生的不适、焦虑甚至痛苦状态。

正常大脑会自动过滤背景噪音——你可以在咖啡馆工作，因为大脑把隔壁桌的谈话"压"到了背景里。感官过载时，这种过滤失效，**所有输入同等涌入意识**。

## 与 ADHD 的关系

ADHD 大脑的**感觉门控（Sensory Gating）**功能异常——本应被过滤掉的无关注入没有被抑制，全部进入意识加工。

### 机制：感觉门控

感觉门控是大脑对重复/无关刺激的自动抑制机制。典型指标是 **P50 抑制**（EEG 测量）：正常大脑听到第二个相同声音时反应减弱，ADHD 大脑的抑制率显著降低。

**结果**：ADHD 大脑的感官"大门"关不上，所有外界信息同等涌入，像收音机同时播放所有频道。

## 日常表现

| 表现 | 背后机制 |
|------|----------|
| 嘈杂环境中完全无法工作（开放办公室头疼） | 无法过滤背景人声 |
| 对衣物标签、材质极度敏感 | 触觉过滤不足 |
| 强光/荧光灯下容易疲劳烦躁 | 视觉刺激过度 |
| 多人同时说话时大脑"死机" | 听觉信息处理过载 |
| 突然的大声音会引发强烈情绪反应 | 惊吓反射缺乏习惯化 |
| 超市/商场逛一会儿就身心俱疲 | 多感官输入叠加 |

## 与 ASD（自闭症谱系）的关系

感官过载在 ADHD 和 ASD 中都极常见，且两者**高共病**（同时出现的概率远高于随机）。区别在于：
- ASD 的感官敏感更可能与固定的感官偏好和刻板行为相关
- ADHD 的更可能随注意力状态波动（专注时过滤变好、疲劳时更差）

## 常见应对策略

| 策略 | 原理 |
|------|------|
| **降噪耳机/白噪音** | 减少听觉通道输入，降低过滤负担 |
| **低刺激工作环境** | 单独办公室、调暗灯光、减少视觉杂乱 |
| **触觉适应** | 剪掉标签、选纯棉/宽松衣物 |
| **规律休息** | 疲劳是感官过载的最大放大器 |
| **感官休息** | 定时闭眼几分钟、去安静角落恢复 |
| **减少蓝光** | 屏幕蓝光持续刺激加重视觉疲劳 |
