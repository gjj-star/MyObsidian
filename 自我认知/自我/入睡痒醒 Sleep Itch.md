# 入睡痒醒 Sleep Itch

**英文**：Hypnagogic Sensory Distortion（入睡期感觉异常）；Hypnic Jerk（入睡抽动）；Histamine（组胺）；C 纤维（C-fiber，痒觉神经纤维）

快睡着时突然某处皮肤奇痒（像被蚊子叮），醒过来挠一挠发现什么也没有——没有蚊子、没有红疹、没有过敏痕迹。

**这是一个极其常见的生理现象，不是病。**

## 四种最可能的机制

1. **入睡期感觉异常（Hypnagogic Sensory Distortion）**：大脑从清醒切换到睡眠时，感官过滤系统会"提前下班"。清醒时大脑自动压制了大量微小信号（衣服的触感、皮肤的微弱痒感、肌肉的微振动），入睡临界点时这些抑制解除——**随机神经放电被解读为真实感觉**。入睡瞬间的"感觉要掉下去"（入睡抽动）、"听到有人叫名字"（入睡幻觉）与突然痒是同一回事：大脑切换模式时的信号误读。
2. **注意力聚焦放大**：白天忙、有外部刺激，注意力分散，微小的皮肤感觉被忽略。安静躺下闭眼后，**注意力无处可去，集中到身体感受上**——平时完全觉察不到的轻微刺激被放大。
3. **组胺的昼夜节律**：组胺（Histamine）除了介导过敏，还是大脑中的神经递质，调节觉醒。**夜间组胺在皮肤中自然释放达到高峰**，刺激皮肤的痒觉 C 纤维。这不是过敏，是生理性的。
4. **体温调节期的血管扩张**：入睡时核心体温下降，皮肤血管扩张把热量散发出去。血管扩张过程激活了皮肤中的痒觉 C 纤维——和组胺释放叠在一起，痒感更明显。

## 可操作的缓解方法

| 方法 | 原理 |
|------|------|
| 温水洗澡（别过热） | 稳定体温，减少入睡时血管剧烈扩张 |
| 睡前涂身体乳 | 干燥会让痒感阈值大幅降低 |
| 纯棉床品 | 化纤的微摩擦持续刺激痒觉 C 纤维 |
| 保持卧室凉爽（18-22°C） | 减少入睡降温的幅度 |
| 减少睡前 1h 蓝光 | 屏幕蓝光抑制褪黑素，延长入睡期（容易痒的阶段） |
| 不挠、转移注意 | 挠会释放更多组胺，越挠越痒。起身走走、冷水拍拍 |

## 什么情况下该看医生

- 每晚都发生且严重影响入睡
- 伴有皮疹、荨麻疹
- 伴有全身其他症状（黄疸、淋巴结肿大等）

以上情况需要排除：慢性荨麻疹、胆汁淤积（肝病）、缺铁性贫血、周围神经病变等。
